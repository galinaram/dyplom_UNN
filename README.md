## 🎯 Описание проекта

Данный программный комплекс предназначен для анализа устойчивости состояния равновесия системы электрододержателей дуговой сталеплавильной печи (ДСП). Колебания электродов могут негативно влиять на качество плавки и ресурс оборудования. Проект реализует математическую модель системы и применяет метод **D-разбиения** для определения областей устойчивости по параметрам системы.

**Цель работы:** Исследовать влияние параметров электродинамической силы и запаздывания на устойчивость системы, чтобы определить критические режимы работы ДСП.

## 📐 Математическая модель

Модель основана на системе дифференциальных уравнений с запаздывающим аргументом, описывающей **крутильные колебания** трех взаимовлияющих электрододержателей:

*   **Уравнения движения:** Учитывают моменты инерции (`J`), демпфирование (`b`), жесткость (`c`).
*   **Электродинамическая сила:** Описывается нелинейной функцией от тока дуги (`I`) и зазора (`lg`), с параметрами `α` и `β`.
*   **Запаздывание (`τ`):** Учитывает инерционность системы регулирования.

Для анализа используется частотный критерий **Найквиста** и построение **годографа** передаточной функции на комплексной плоскости. Устойчивость состояния равновесия определяется положением критической точки `(-1, 0)` относительно построенной кривой D-разбиения.

## ⚙️ Функциональность

*   **Графический интерфейс пользователя (GUI):** Интуитивно понятное приложение на Tkinter.
*   **Задание параметров системы:** Возможность изменения всех ключевых параметров модели (маoment инерции, жесткость, ток, геометрические размеры и т.д.).
*   **Визуализация результатов:** Построение границы D-разбиения на комплексной плоскости.
*   **Автоматический анализ:** Программа автоматически проверяет условие устойчивости по критерию Найквиста и выводит текстовый результат.

## 🚀 Установка и запуск

### Предварительные требования

*   Python 3.8 или новее
*   Менеджер пакетов `pip`

### 1. Клонирование репозитория

```bash
git clone https://github.com/galinaram/dyplom_UNN.git
cd dyplom_UNN
```

### 2. Установка зависимостей
Рекомендуется создать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Для Linux/MacOS
# или
venv\Scripts\activate     # Для Windows
```
Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```
### 3. Запуск приложения
Из корневой директории проекта выполните команду:
```bash
python main.py
```
После этого откроется главное окно приложения.

## 🖥️ Использование

1. Запустите программу (python main.py).
2. На главном экране вы увидите описание проекта и навигационные кнопки.
3. Перейдите на вкладку "Параметры". Задайте необходимые значения или оставьте значения по умолчанию.
4. Перейдите на вкладку "Построение границы D-разбиения".
5. При необходимости задайте диапазон частот ω (Омега) и шаг вычислений.
6. Нажмите кнопку "Построить график".
7. На графике отобразится кривая D-разбиения. Система автоматически проанализирует устойчивость и выведет вердикт: "Состояние равновесия устойчиво/неустойчиво".

## 📊 Результаты

В результате работы программы строится замкнутая кривая на комплексной плоскости (годограф). Устойчивость системы определяется по критерию Найквиста: если точка (-1, 0) лежит вне этой кривой, то состояние равновесия устойчиво. В противном случае — неустойчиво.

Программа позволяет техническим специалистам и исследователям определять критические комбинации параметров работы ДСП, что способствует повышению надежности и эффективности технологического процесса.
